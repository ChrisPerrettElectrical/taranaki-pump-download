How to install

  1. Tap Download Taranaki Pump.
  2. Open the downloaded APK file.
  3. If Android asks for permission, select Allow installation from this source.
  4. Tap Install.
  5. Open Taranaki Pump.
  6. Sign in using the account details supplied by Chris Perrett Electrical Solutions.
